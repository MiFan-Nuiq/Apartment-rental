# 公寓租赁管理系统 测试用例

## 一、测试环境与准备

### 1.1 系统信息
- 后端：Spring Boot + Spring Security(JWT) + JPA
- 前端：Vue3 + Vue Router + Axios
- 数据存储：关系型数据库（JPA 自动建表）

### 1.2 默认初始化账号（`DataInitializer.java`）
| 用户名 | 密码 | 真实姓名 | 角色 | 说明 |
| --- | --- | --- | --- | --- |
| admin | 123456 | 系统管理员 | ADMIN | 管理员 |
| landlord | 123456 | 张房东 | LANDLORD | 房东 |
| tenant | 123456 | 李租户 | TENANT | 租户 |

> 注意：仅当数据库 `users` 表为空时才会初始化上述账号。

### 1.3 接口鉴权规则（`SecurityConfig.java`）
- `POST /api/auth/**`、`GET /api/auth/info`：`/api/auth/**` 全部放行，无需 Token。
- `/uploads/**`：静态资源放行，无需 Token。
- 除 `/api/auth/**` 与 `/uploads/**` 外的所有 `/api/**` 接口：**必须携带合法 Bearer Token**，否则返回 401 未认证。
- JWT 格式：请求头 `Authorization: Bearer <token>`。

### 1.4 统一返回结构（`ApiResponse`）
```json
{ "code": 200, "message": "success", "data": ... }
```
- 业务成功但异常时 `code` 也可能为 200，`message` 带提示文字（见各用例）。
- 未认证时由 Spring Security 返回 401。

## 十六、测试数据准备建议
1. 建议先通过 `/api/auth/register` 或系统自带账号创建：房东（LANDLORD）、租户（TENANT）各至少一名。
2. 测试合同时间冲突、到期自动处理前，需先创建 `生效中` 的合同与对应的 `已出租` 公寓。
3. 因 `/api/**` 均需登录，执行各用例前先调用 `POST /api/auth/login` 获取 token，并在后续请求头携带 `Authorization: Bearer <token>`。
4. 评价、收藏等用例涉及多个角色的关联数据，请按 租户-合同-房源 的依赖顺序构造。
